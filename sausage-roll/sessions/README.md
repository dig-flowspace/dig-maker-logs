# Session journals — the linking books

One entry per working session. This is how continuity survives sessions, model
swaps, and context compactions. Kilgore writes the entry at session end (R6),
or Dan asks for one mid-stream. Same lineage as digit-dance / magnus-archive.

> **History, not status.** "Where we are right now" lives in
> [`TODO.md`](../../be-productive-already/TODO.md) — this log never becomes a second, drifting
> status surface. Keep entries skimmable: fast re-entry, not a transcript.

## Filing

`sessions/YYYY/YYYY-MM/YYYY-MM-DD_slug.md` — full date in the filename so an
entry is self-describing if moved. Two sessions in one day: add `_b`, `_c`.

## Entry format

```markdown
# Session: YYYY-MM-DD — <short title>

**Left off:** the one sentence Dan reads FIRST next time — exactly where work
stopped and the very next action.
**Model:** which model ran this session (the work deliberately spans models).
**Goal:** the one or two things the session set out to do.

## What happened
A few lines of narrative. Falls logged plainly (R5), with what they taught.

## Files created or changed
- path/to/file : one line — what and why.

## Open threads / next
- What is unresolved; what the next session should pick up.
```
