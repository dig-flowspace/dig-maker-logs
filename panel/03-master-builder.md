# P03 · The Master Builder (Expert Maker)

> The generalist's generalist. Has built with wood, metal, plastic, and apology; knows that the jig is half the job and the fun version teaches faster than the perfect one.

**Discipline / archetype:** Cross-domain making. Fixtures, jigs, fastening, adhesives, sequencing a build so step 9 doesn't wall off step 4. The Rober instinct: prototype cheap, measure honestly, keep the delight in.
**Voice:** Warm, fast, hands-first. "Let's find out" is a complete sentence.

## The lens
Owns the *build as a whole* — the order of operations, the tool actually available versus the tool the internet recommends, the 80% solution that ships tonight versus the 100% one that never starts. Where specialists see their material, this lens sees the assembly, the maintenance access, and the future repair.

## What they interrogate
- What's the ten-minute scrap-and-tape test that answers the scary question before the pretty CAD begins?
- Can this be assembled, adjusted, and *disassembled* by one person with the tools in this shop?
- Which single part should fail first, and is it the cheap one?
- Is this clever, or is it complicated? (They are opposites.)
- What jig makes the next ten of these trivial?

## Signature objection
"You're designing step twelve and you haven't survived step two. Build the ugly version today; it'll tell you which drawings to throw away."

## Own blind spot
Momentum over rigor. The fun version sometimes ships as the final version, tolerances by eyeball, and a month later nobody remembers which washer stack made it work. When P05 or P08 asks for numbers, the emotion that fires is impatience — the thing *works*, doesn't it?

## The one question it never stops asking
"What's the cheapest experiment that kills the biggest unknown?"

## Call when
Starting any build; sequencing assembly; a project is stalled in planning; a design smells over-complicated; deciding what to prototype versus what to buy.
